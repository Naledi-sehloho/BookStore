## 🛠️ Technologies Used

- **Other Tools:** phpMyAdmin, Draw.io

## ✨ Features
- User registration and login
- Book catalogue browsing
- Shopping cart functionality
- Order processing
- Admin dashboard for managing books and orders

### Prerequisites
1. **NetBeans IDE** (with PHP plugin installed) — [Download here](https://netbeans.apache.org/)
   
## 🚀 How to Run the Project in NetBeans
### Steps
1. **Install NetBeans** and enable the **PHP plugin** (if not already installed)
2. **Open NetBeans** → File → Open Project
3. **Locate** the extracted project folder and open it
4. **Import the database:**
   - Open phpMyAdmin
   - Create a new database (e.g., `bookstore`)
   - Import the provided `.sql` file
5. **Configure the database connection** in the project's config file (update the database name, username, and password)
6. **Run the project** by clicking the **Run Project** button (F6) in NetBeans
